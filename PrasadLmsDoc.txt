MODULE WISE HIGH LEVEL FLOW ,
1. Admissions Module Flow
Student Enquiry Created
    ↓
Admin Reviews Enquiry
    ↓
Application Submitted
    ↓
Admin Approves / Rejects Application
    ↓
If Approved:
    → Student Account Created
    → Login Credentials Sent via Email

2. Manage Company Module Flow
Academic Session Flow
Super Admin / Admin Creates Academic Session
    ↓
Courses Assigned To Academic Session
    ↓
Batches Created For Courses

Team Management Flow
Admin Creates Team
    ↓
Teachers / Admins Assigned To Team
    ↓
Team Access & Responsibilities Managed

Course Package Management Flow
Teacher/Admin Creates Course
    ↓
Set Course Details
    → Course Name
    → Level
    → Start Date
    → End Date
    → Total Seats
    ↓
Publish Course
    ↓
Track Booked Seats & Course Status

3. Membership Module Flow
Student Enrolled Into Course
    ↓
Membership Record Created
    ↓
Payment Added
    ↓
System Calculates:
    → Amount Paid
    → Due Amount
    → Grace Period
    ↓
Membership Status Updated
    → Active
    → Grace Period
    → Expired

4. CRM Dashboard Flow
Dashboard Loads System Statistics
    ↓
Display:
    → Total Students
    → Active Courses
    → Team Members
    → Outstanding Fees
    → Live Classes Today
    ↓
Admin Accesses Quick Actions:
    → Add Student
    → Create Batch
    → Add Announcement
    → Manage Payments
    → View Notifications

5. Course Creation Module Flow
Teacher/Admin Creates Course
    ↓
Add Course Modules
    ↓
Add Lessons To Modules
    ↓
Attach PDFs / Resources
    ↓
Configure Meet Link
    ↓
Save As Draft
    ↓
Publish Course
    ↓
Generate Invite Link

6. Course Planning & Logging Flow
Course Planning Flow
Teacher Creates Course Planner
    ↓
Select Lesson
    ↓
Schedule Date & Time
    ↓
Set Recurring Schedule (Optional)
    ↓
Planner Saved

Course Logging Flow
Scheduled Session Conducted
    ↓
Teacher Marks Session Status
    → Completed
    → Missed
    → Cancelled
    ↓
Remarks Added
    ↓
Course Log Stored

7. Course List Dashboard Flow
Student Logs Into LMS
    ↓
System Fetches Enrolled Courses
    ↓
Display:
    → Active Courses
    → Course Status
    → Upcoming Sessions
    ↓
Student Opens Course
    ↓
Access Lessons & Live Sessions

8. Live Sessions Module Flow
Teacher Schedules Live Session
    ↓
Session Linked To Course
    ↓
Students Receive Notification
    ↓
Students Join Google Meet
    ↓
Teacher Marks Attendance
    ↓
Attendance Stored
    ↓
Session Marked Completed

9. Announcement Module Flow
Admin / Teacher Creates Announcement
    ↓
Choose Audience:
    → Global
    → Course Specific
    ↓
Publish Announcement
    ↓
Notifications Sent To Target Users

10. Enrollment & Invite Flow
Teacher Generates Invite Link
    ↓
Student Opens Invite Link
    ↓
System Verifies Login
    ↓
Enrollment Created
    ↓
Membership Record Created
    ↓
Student Gets Course Access

11. Attendance Flow
Student Joins Live Session
    ↓
Teacher Opens Attendance Panel
    ↓
Mark:
    → Present
    → Absent
    → Blocked
    ↓
Attendance Stored In System

12. Notification & Email Flow
System Event Triggered
    ↓
Examples:
    → Application Approved
    → Payment Successful
    → Course Enrollment
    → Live Session Scheduled
    ↓
Notification Created
    ↓
Email Sent To User
