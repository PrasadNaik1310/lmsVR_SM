# Membership Module - API Contract (Iteration 1)

## Version

**Version:** v1.0
**Module:** Membership Management
**Status:** Approved for Development

---

# Overview

The Membership Module is responsible for managing student fee records, payment tracking, outstanding dues, grace periods, and membership status.

Memberships are automatically created when a student is enrolled in a course.

---

# Scope

## Included

* Membership Dashboard
* Membership Listing
* Membership Details
* Payment Recording
* Payment History
* Outstanding Fee Tracking
* Grace Period Management

## Excluded

* Payment Gateway Integration
* Refunds
* Installment Plans
* Invoice Generation
* GST/Tax Handling
* Financial Reports

---

# Business Rules

## Membership Creation

Memberships are automatically created during enrollment.

```text
Student Enrollment
        ↓
Membership Created
```

No manual membership creation endpoint is provided.

---

## Fee Assignment

Course fees are entered during enrollment and stored in the membership record.

Example:

```text
Student
    ↓
Enrollment
    ↓
Fee Assigned
    ↓
Membership Created
```

---

## Membership Statuses

```text
ACTIVE
GRACE_PERIOD
EXPIRED
```

Status is automatically calculated by the system.

Manual status updates are not allowed.

---

## Grace Period

Grace period duration:

```text
30 Days
```

Grace expiry is calculated from the latest successful payment date.

---

## Payment Rules

### Rule 1

Payment amount must be greater than zero.

### Rule 2

Payment amount cannot exceed due amount.

### Rule 3

Every payment creates a new payment record.

Existing payment records must never be modified.

### Rule 4

Membership status must be recalculated after every payment.

---

# Membership Status Logic

## ACTIVE

Condition:

```text
Due Amount = 0
```

Access:

```text
Attend Classes
Access Lessons
Submit Assignments
Attendance Marked
```

---

## GRACE_PERIOD

Condition:

```text
Due Amount > 0
Current Date <= Grace Expiry Date
```

Access:

```text
Attend Classes
Access Lessons
Submit Assignments
Attendance Not Marked
```

---

## EXPIRED

Condition:

```text
Due Amount > 0
Current Date > Grace Expiry Date
```

Access:

```text
No Access
```

# 4. Record Payment

## Endpoint

```http
POST /lms/payments
```

## Permission

```text
payment.create
```

## Request Body

```json
{
  "membership_id": "uuid",
  "amount": 10000,
  "payment_method": "UPI",
  "transaction_reference": "TXN123456"
}
```

## Validation

```text
Membership Exists
Amount > 0
Amount <= Due Amount
```

## Transaction Flow

```text
Create Payment Record
        ↓
Update Amount Paid
        ↓
Update Due Amount
        ↓
Update Grace Expiry Date
        ↓
Recalculate Membership Status
```

All operations must execute inside a database transaction.

## Success Response

```json
{
  "success": true,
  "payment_id": "uuid",
  "updated_due_amount": 10000,
  "membership_status": "GRACE_PERIOD"
}
```

## Error Responses

```text
404 Membership Not Found
400 Invalid Amount
409 Payment Exceeds Due Amount
500 Transaction Failed
```
